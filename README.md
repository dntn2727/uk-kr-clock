# UK · KR 시계

영국과 한국 시간을 한눈에 보는 아이패드용 상시 시계.

- 요일이 같으면 요일·날짜를 가운데로 합치고, 다르면 좌우로 나눔
- 화면 테두리가 60초 동안 채워지며 초를 표시
- 국기 후광과 타임라인 막대 색으로 각 도시의 해 높이(낮·밤)를 표시
- 서머타임 자동 반영

## 아이패드 설치

1. Safari로 이 페이지의 GitHub Pages 주소를 연다
2. 공유 버튼 → **홈 화면에 추가**
3. 설정 → 디스플레이 및 밝기 → 자동 잠금 → **안 함**
4. 가로로 두고 제어 센터에서 화면 회전 잠금

## 테스트용 주소 옵션

- `?at=2026-09-24T14:59:50Z` — 지정한 시각부터 시작
- `?speed=60` — 시간을 60배 빠르게
- `?theme=classic` — 처음 시안 색
